# Image Guide — Explore Dima Hasao Website

Every image the code expects, with its exact path and filename. Shoot or source
a JPEG for each, name it **exactly** as shown below, and drop it into the matching
folder — the site will pick it up automatically, no code changes needed.

Recommended size: destinations/packages/gallery ~1600×1200px (4:3), about ~1200×1500px
(4:5 portrait). Keep each file under ~500KB for fast loading (export at ~80% JPEG quality).

Until you add your own photos, every one of these slots is filled with a generated
placeholder in the site's own colour palette, labelled with an "ADD YOUR PHOTO HERE"
tag — so the site looks intentional, not broken, in the meantime. Just overwrite each
file (same name) whenever you have the real shot.
